# Muhammed Ameen T — Personal Portfolio

A responsive and animated developer portfolio built with **React**, **Tailwind CSS**, and **Framer Motion**. It highlights my MERN stack expertise, real-world projects, and technical clarity — all wrapped in a clean UI optimized for onboarding and developer experience.

## 🚀 Features

- ⚡ Fast, responsive layout with Tailwind CSS
- 🎬 Smooth animations using Framer Motion
- 🧠 Tech stack icons with tooltips
- 📄 Downloadable CV (hosted via Google Drive)
- 🛠️ Project showcase with live links and GitHub repos
- 🌐 SEO and social preview metadata
- 🧩 Modular components for easy scaling

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, Framer Motion
- **Icons**: Devicon, SVG assets
- **Deployment**: Vercel / Netlify / Render (choose your host)
- **CV Hosting**: Google Drive direct download
